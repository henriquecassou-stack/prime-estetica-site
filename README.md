# Prime Estética Avançada JB — prévia do site

Prévia one-page da clínica Prime Estética Avançada JB (Pinhais/PR).

- `prime-estetica.html` — página para editar (usa as imagens da pasta `img/`)
- `prime-estetica-arquivo-unico.html` — versão com as imagens embutidas, para enviar como um único arquivo
- `gerar-arquivo-unico.py` — gera a versão em arquivo único depois de editar: `python gerar-arquivo-unico.py`

Os tratamentos ficam na lista `TRATAMENTOS`, no fim do `prime-estetica.html`.

Desenvolvido por CODA.
